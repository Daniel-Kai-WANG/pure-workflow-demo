    HOW IT WOULD WORK

    Each tool has a clear job.

    Staff work through Discord. Monday holds operational work. The workflow uses only authorised sources.

    Gmail + Drive
    Supply CC’d correspondence and authorised project material.
    OpenAI
    Interpret the request and suggest changes using relevant context.
    n8n
    Connect the systems and execute the approved actions.
    Discord
    Show proposals to authorised reviewers and report outcomes.
    Monday
    Keep the current tasks, owners, dates and statuses.

    FROM STEVEN’S BRIEF

    Keep the starting model controlled.

    CC-only email intake, client separation, staff permissions, human approval and an activity record. Briefs, notes and transcripts can also start the same workflow.

    SUGGESTED PILOT · TO AGREE

    Start small, then measure usefulness.

    Begin with a small set of clients and reviewers. Test historical examples before live use. Add Ask Pure and proactive alerts once intake and updates are reliable.
